Earth Explorer
Earth day/night maps: Solar System Scope, https://www.solarsystemscope.com/textures/ , CC BY 4.0 https://creativecommons.org/licenses/by/4.0/
Desktop: drag to orbit, scroll / +,- keys / on-screen buttons to zoom, click cities. Mobile: scan horizontal plane, tap to place, drag/tilt to orbit, pinch or on-screen buttons to zoom.
Virtual cockpit camera is rendered as an overlay: the tracked AR camera is NEVER moved. This is a stylized cockpit view, not a physically registered camera orbit.
Android module is required via Unity Hub; enable ARCore in XR Plug-in Management and run Project Validation. Use OpenGLES3, IL2CPP, ARM64, minimum API 24.
